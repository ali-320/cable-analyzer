RADWI Cable Analyzer — Changes Record

Requested changes
-----------------
The requested feature was to use the observed INA219 current ranges to improve state detection:

- Active mobile charging normally appears in the 0.xxx A range.
- A fully charged mobile normally continues drawing a smaller 0.0xx A current.
- When no mobile is connected, only a very small 0.00xx A leakage current is present.
- These ranges should be configurable in config.toml.
- The corresponding state logic, calculations, simulation behavior, tests, and documentation should be updated.
- The implementation must distinguish a fully charged mobile from an absent mobile and must not treat the no-mobile leakage range as evidence that charging completed.

Confirmed candidate samples should be treated as the new state—or otherwise excluded—so the same correction applies to `CHARGING`, `CHARGED`, `NO_PHONE`, and `IDLE` transitions.
