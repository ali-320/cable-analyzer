Cable Analyzer - Payloads sent to the Supabase database
=======================================================

Every payload is built in src/telemetry/remote.py and POSTed to the PostgREST
endpoint:

  sessions: POST {SUPABASE_URL}/rest/v1/sessions?on_conflict=session_id
  samples:  POST {SUPABASE_URL}/rest/v1/samples?on_conflict=session_id,sample_index

For each payload below:
  - first JSON  = column name and its database type
  - second JSON = a realistic example of the values


1. SESSION PAYLOAD  (one row per completed session)
---------------------------------------------------

Columns and types:
{
  "session_id":        "TEXT (primary key)",
  "device_id":         "TEXT (must equal pi-zero-2w-01 for RLS)",
  "mode":              "TEXT (auto | probe | charge)",
  "v_target":          "DOUBLE PRECISION",
  "length_m":          "DOUBLE PRECISION",
  "phone_expected":    "BOOLEAN",
  "started_at":        "DOUBLE PRECISION (epoch seconds, nullable)",
  "ended_at":          "DOUBLE PRECISION (epoch seconds, nullable)",
  "charging_detected": "BOOLEAN",
  "v_present":         "BOOLEAN",
  "fault_reason":      "TEXT (nullable)",
  "probe_json":        "JSONB",
  "verdict_json":      "JSONB",
  "created_at":        "TIMESTAMPTZ (ISO 8601 string)"
}

Example values:
{
  "session_id":        "20260812T093917321424",
  "device_id":         "pi-zero-2w-01",
  "mode":              "probe",
  "v_target":          5.0,
  "length_m":          1.0,
  "phone_expected":    true,
  "started_at":        1755002357.0,
  "ended_at":          1755002392.0,
  "charging_detected": true,
  "v_present":         true,
  "fault_reason":      null,
  "probe_json":        { "...": "see section 3" },
  "verdict_json":      { "...": "see section 2" },
  "created_at":        "2026-08-12T09:39:17.321424+00:00"
}

Note: started_at/ended_at are epoch seconds and are null for probe sessions
(probe mode never sets them).


2. VERDICT_JSON  (embedded in the session row, produced by src/analysis/rules.py)
---------------------------------------------------------------------------------

Columns and types:
{
  "session_id":         "TEXT",
  "model":              "TEXT",
  "verdict":            "TEXT",
  "grade":              "TEXT (A | B | C | D | F, nullable)",
  "tags":               "ARRAY of TEXT",
  "confidence":         "DOUBLE PRECISION (0.0 to 1.0)",
  "evidence":           "ARRAY of TEXT",
  "limitations":        "ARRAY of TEXT",
  "confidence_details": "OBJECT",
  "confidence_details.r_mean":           "DOUBLE PRECISION",
  "confidence_details.r_dvdi":           "DOUBLE PRECISION (nullable)",
  "confidence_details.n_busy":           "INTEGER",
  "confidence_details.r_std":            "DOUBLE PRECISION",
  "confidence_details.scale":            "DOUBLE PRECISION",
  "confidence_details.confidence_base":  "DOUBLE PRECISION",
  "confidence_details.agreement":        "DOUBLE PRECISION (nullable)",
  "confidence_details.voltage_penalty":  "DOUBLE PRECISION"
}

Example values:
{
  "session_id": "20260812T093917321424",
  "model":      "rules-v1",
  "verdict":    "Grade A: Excellent",
  "grade":      "A",
  "tags":       ["HIGH_LOSS"],
  "confidence": 0.873,
  "evidence": [
    "R_mean=18 mOhm (normalized to 1 m)",
    "V_min=4.980 V (target 5.0 V)",
    "eta=99.6%"
  ],
  "limitations": [
    "single measurement point; loop R includes connectors and the CH224K path (baseline subtracted)",
    "absolute R biased by charger tolerance (+/-5%); same-current differential calibration mitigates"
  ],
  "confidence_details": {
    "r_mean":          0.017883,
    "r_dvdi":          null,
    "n_busy":          240,
    "r_std":           0.0012,
    "scale":           0.02,
    "confidence_base": 0.913,
    "agreement":       null,
    "voltage_penalty": 1.0
  }
}

Note: r_dvdi and agreement are null when no reliable negative V/I slope
exists. voltage_penalty is 1.0 normally, 0.85 when the display reference
voltage is not 5 V.

4. SAMPLE PAYLOAD  (one row per reading, posted in batches of up to 500)
------------------------------------------------------------------------

Columns and types:
{
  "session_id":   "TEXT",
  "device_id":    "TEXT (must equal pi-zero-2w-01 for RLS)",
  "sample_index": "INTEGER (starts at 0, unique per session)",
  "t":            "DOUBLE PRECISION (seconds since acquisition start)",
  "voltage_v":    "DOUBLE PRECISION",
  "current_a":    "DOUBLE PRECISION",
  "power_w":      "DOUBLE PRECISION",
  "state":        "TEXT (NO_SOURCE | NO_PHONE | CHARGING | CHARGED | FAULT | VERIFICATION | PROBE)",
  "valid":        "BOOLEAN"
}

Example values:
{
  "session_id":   "20260812T093917321424",
  "device_id":    "pi-zero-2w-01",
  "sample_index": 0,
  "t":            1.2345,
  "voltage_v":    4.98,
  "current_a":    0.512,
  "power_w":      2.55,
  "state":        "CHARGING",
  "valid":        true
}

A full session is sent as an array of these rows, for example:
[
  { "session_id": "20260812T093917321424", "device_id": "pi-zero-2w-01", "sample_index": 0, "t": 1.2345, "voltage_v": 4.98, "current_a": 0.512, "power_w": 2.55, "state": "CHARGING", "valid": true },
  { "session_id": "20260812T093917321424", "device_id": "pi-zero-2w-01", "sample_index": 1, "t": 1.2745, "voltage_v": 4.98, "current_a": 0.513, "power_w": 2.55, "state": "CHARGING", "valid": true }
]
